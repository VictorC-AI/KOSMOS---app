# KOSMOS

App de organização pessoal do Victor (agenda, tarefas, estudos, finanças). Ele é estudante de Sistemas de Informação e quer aprender enquanto constrói: explique decisões técnicas em linguagem simples.

Antes de qualquer tarefa:

1. Leia `docs/decisoes.md`. Decisão pendente não é decisão tomada.
2. Siga as skills em `.claude/skills/`: `kosmos-convencoes` sempre; `kosmos-design-system` para qualquer coisa visual; `kosmos-dados` para banco, datas, dinheiro, autorização e integrações.
3. Rode `git status` e preserve alterações do Victor.

Depois de mudar código, rode `npm run check` e relate o resultado real.
